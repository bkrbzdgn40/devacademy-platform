# DevAcademy

DevAcademy is an interactive platform for learning programming languages, software engineering concepts, and modern technology stacks.

**Status:** Product discovery / repository initialization. No working application has been released yet.

This repository will be managed as a private, modular monorepo. The first deliverable is a reviewed product and architecture baseline, followed by a small, testable learning vertical slice.

## Product direction

- Learn concepts through explanation, runnable examples, exercises, and feedback.
- Connect languages, software concepts, and tech stacks in a consistent knowledge model.
- Practice safely in an isolated code execution environment.
- Follow source-attributed technology developments linked to relevant lessons.
- Support Turkish and English over time.

Development plans and operational rules will be added through pull requests. Do not assume that a proposed feature or service already exists.

## Working agreements

- Protect `main`; develop using feature branches and reviewed pull requests.
- Never execute learner-submitted code inside the web application process.
- No production secrets in the repository.
- Keep the scope small enough to validate learning outcomes.
